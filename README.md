# OGX Systems

OGX Systems is the strategic software foundation for **OGX PRIME** and **THARA**, with a flagship **All-In-One.OS** platform and a tactical **MiniOS** runtime profile.

## Workspace Structure

```text
.
├── apps/
│   └── web/          # Vite + React premium dark-tech landing experience
├── docs/
│   ├── architecture.md
│   └── roadmap.md
└── package.json      # Root scripts proxying to apps/web
```

## Product Surface

The web experience highlights:

- Hero: premium OGX positioning
- Pillars: intelligence, resilience, velocity
- Platform layers: experience, intelligence, core systems, infrastructure
- Operating model: strategic command + autonomous delivery
- Module catalogs:
  - All-In-One.OS modules
  - MiniOS modules (THARA edition)
- Roadmap milestones for OGX PRIME and THARA
- Documentation support entry points
