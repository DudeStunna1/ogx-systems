# ogx-systems

OGX Systems is now scaffolded as a premium web foundation for the OGX brand, with room to grow into a broader platform for operations, automation, and governance.

## Repository structure

- `apps/web` — Vite + React frontend for the OGX Systems public-facing experience
- `docs/architecture.md` — target platform architecture and growth model
- `docs/roadmap.md` — execution priorities for turning this foundation into a larger system

## Local development

From the repository root:

```bash
npm install --prefix apps/web
npm run dev
```

## Available commands

- `npm run dev` — start the OGX Systems website locally
- `npm run build` — create a production build
- `npm run lint` — run ESLint for the frontend
